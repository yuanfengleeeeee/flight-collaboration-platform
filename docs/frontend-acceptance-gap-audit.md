# 前端正式验收前端后端缺口审计

更新时间：2026-09-04

本文以当前 `/frontend` 代码和 Core/Edge OpenAPI 为准，区分“代码已存在”和“仍是页面蓝图”，不把设计文档中的计划当作已实现功能。

## 已落实

| 范围 | 当前结果 |
| --- | --- |
| 航班事实 | 管理端只读 `GET /api/v1/flights`；航班新增、到达、离港、取消不再注册为管理端 API。航班接入边界为 `internal/integration/flight.Provider`，批量接收入口为 `/internal/integration/v1/flight-source/sync`，到达事件入口为受 `X-Flight-Source-Key` 保护的 `/internal/integration/v1/flights/{flightPublicID}/arrival`。数据库保留 `source_provider`、`external_flight_id`，开发种子数据使用 `development` 来源。 |
| 岗位/能力匹配 | Core 已按班组、区域、岗位编码、能力、在岗状态、启用状态、主成员关系和计划时间冲突生成 Candidate，并保存岗位/能力快照。 |
| 员工建档 | 员工可由管理端新增、编辑、启停用和重置密码；工号服务端强制为 4–12 位数字，岗位编码为小写稳定编码，能力最多 64 个且必须为小写编码；数据库仍对工号做唯一约束。 |
| 组织与任务配置 | 管理端已支持区域/班组新增、编辑、启停用，任务模板新增、编辑、启停用，以及管理身份新增、角色/名称编辑和启停用；队长身份创建时可绑定区域或班组 Scope。 |
| 管理查询 | Core 管理资料、任务、人员、Assignment、异常、航班、模板和管理身份接口均返回 `items/page/page_size/total`，MySQL 由数据库执行 Count、Limit、Offset。 |
| 员工历史/通知 | Edge 历史和通知接口已支持服务端分页；Web 和两个小程序通过公开 Edge 接口读取。员工任务列表保留完整个人快照，这是断线恢复契约，不是管理端全量查询。 |

## 文档与当前路由的差异

`frontend/docs/page-design.md` 中仍保留了早期的嵌套路由写法（例如 `/tasks/templates`、`/personnel/positions`、`/system/users-roles`）。当前 Admin Web 实际使用扁平路由 `/templates`、`/positions`、`/users-roles` 等；正式验收应以 `frontend/apps/admin-web/src/app/App.tsx` 的实际路由为准，后续应统一页面文档，避免测试人员按旧地址验收。

## 结论

岗位能力匹配后端和管理端 `/positions` 页面已经交付；组织、人员、任务模板、管理身份等主数据维护也已具备新增、编辑或启停用路径，已有身份 Scope 已可通过区域/班组 public ID 编辑。人员状态、事件、审计、Scope、诊断页面已接入当前公开 Core 查询。管理端主列表和状态历史已使用数据库分页，员工任务列表继续保持完整快照语义。正式验收的剩余重点是空结果/数据变化后的分页专项验收、岗位能力引用保护和角色权限验收、真实航班 Provider、平台通知、生产身份和发布配置。

## 按依赖顺序执行的剩余任务

1. **分页大数据验收**：`frontend/e2e/admin-pagination.spec.ts` 已覆盖 100+ 数据的首/二页、首/末页、统一响应元数据、UTF-8 响应和管理端任务翻页；继续补空结果和删除/停用后页码修正的专门场景。
2. **主数据与权限收口**：当前组织、人员、模板、管理身份的主要新增/编辑/启停用路径以及已有身份 Scope public ID 编辑已完成；继续完成岗位/能力引用保护和角色权限验收。
3. **状态/事件/审计/诊断增强**：筛选字段已接入；继续补管理端通知投递查询、详情抽屉和 request ID/Projection lag 展示，保持 Core Scope 和脱敏边界。
4. **真实航班 Provider 与平台身份**：提供真实航班接口资料、微信/企业微信凭据、HTTPS 通信/回调域名和管理员预置后，完成 Provider、平台通知、管理 SSO 和双平台同一 Staff 线上联调。
5. **发布与可靠性门禁**：用微信开发者工具完成两套小程序真实域名编译/预览/发布；把 Web/小程序 E2E 纳入 CI，并补充 503、重启、网络分区、多副本 fan-out、容量和 p50/p95/p99 性能验收。
